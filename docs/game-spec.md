# 地獄廻線・七獄パック統一カードゲーム版 ゲーム仕様

更新基準日：2026年9月4日  
対象ブランチ：`unified-card-game`

本書は、現在確定している統一カードゲーム版の仕様をまとめる。旧版の駅別ミニゲームは完全廃止されており、本書の対象外とする。未確定事項は推測で補完せず、`TODO` として記載する。

## ゲーム概要

- タイトルは「地獄廻線」。
- プレイヤー7人が地獄行きの列車に乗り、第一から第七までの地獄駅を順番に巡る。
- 全駅で、共通のカード選択・一斉公開・効果処理システムを使用する。
- 各PLは互いに異なる七獄パックを1種類選び、駅ごとにカードを使用する。
- 第七駅終了後、HPなどを基準に表向きの総合順位を決定する。
- 冥貨の裏面にある路線図の断片をココフォリア上で組み合わせた結果により、真のエンディングが分岐する。
- 想定参加者はGM1人＋PL7人、想定プレイ時間は約3時間である。

## 全体進行

1. GMがWeb上でルームを作成する。
2. GMがルームコードをPL7人へ共有する。
3. PLは名前とルームコードを入力して参加する。
4. 導入文を一文ずつ読み上げる。
5. 8分間の自己紹介を行い、各PLが完了を報告する。
6. HPルールを説明する。
7. 七獄パック7種類の得意分野を公開する。
8. PL7人が重複しないパックを1種類ずつ選ぶ。
9. 焦熱、氷結、針山、血の池、餓鬼、修羅、無間の順に進行する。
10. 各駅で規定ターン数だけ、相談、秘密選択、最終確認、一斉公開、効果処理を行う。
11. 第一駅から第六駅では駅順位、支援賞、隠し特殊ボーナスを発表する。第七駅では支援賞と隠し特殊ボーナスを発表し、駅順位は算出しない。
12. WebがGMへ冥貨の配布内容を示し、GMはココフォリアへ手動で反映する。
13. 第一駅から第六駅では、駅結果と報酬の読み上げ後にココフォリア反映待機へ入り、全件の反映確認後にだけGMが5分間の自由時間を開始できる。
14. 第七駅終了後、3分間の最終整線を行う。
15. GMが未反映処理と冥貨状態を監査し、必要な場合だけ補正配置を行って盤面をロックする。
16. GMがココフォリア上の路線図を非公開で判定し、エンディングを確定する。
17. 最終順位と確定したエンディングを表示する。

### 導入「地獄廻線」

以下を正式な導入文とする。GMが本文下部の「次へ」を押すたびに次の本文を全クライアントへ公開し、公開済みのテキストは画面上部へ履歴として残す。画面には「地の文」「小鬼」「車内放送」などの話者見出しを表示しない。最後のテキストまで表示した後の進行操作で、8分間の自己紹介フェーズを開始する。

**地の文**

規則正しい揺れと、車輪が線路を擦る音。

目を開けると、そこは見知らぬ列車の中だった。窓の外には、景色らしい景色はない。

そして車内には、自分を含め、七人の人間がいた。

誰も、この列車に乗った覚えはない。

どうしてここにいるのか。どこへ向かっているのか。

何ひとつ分からないまま、列車だけが進み続けている。

そのとき、勢いよく車両の扉が開いた。

**小鬼**

「はぁ〜い！」

「みなさ〜ん！ お目覚めですかぁ？」

**地の文**

現れたのは、小さな角を生やした奇妙な生き物だった。

車掌帽をかぶり、ぶかぶかの制服を着ている。その手には、人数分の切符が握られていた。

**小鬼**

「いやぁ〜、よかったよかった！」

「七名様、ちゃ〜んと揃ってますねぇ！」

「それでは改めまして」

**地の文**

小鬼は帽子を押さえ、深々と頭を下げる。

**小鬼**

「ようこそ！」

「**地獄廻線へ！**」

**地の文**

聞き慣れない言葉が、車内に響く。

**小鬼**

「この列車はこれから、七つの地獄を順番に巡りま〜す！」

「焦熱、氷結、針山、血の池、餓鬼、修羅……」

「そして最後は、無間地獄！」

「いやぁ、観光列車みたいで楽しそうですねぇ！」

**地の文**

小鬼は楽しそうに笑う。

**小鬼**

「あっ、大事なことを忘れてました！」

少しだけ間を置いて。

その直後。車内放送のチャイムが鳴る。

**――ピンポーン。**

**車内放送**

『まもなく――第一地獄。』

『焦熱地獄。』

**小鬼**

「さぁ！」

「その前に、せっかく七人もいるんですから」

「まずは、お互いのことを知っておきましょうか！」

こうして。

行き先も、降り方も分からないまま。

七人を乗せた地獄廻線は、最初の駅へと走り始めた。

### 自己紹介フェーズ

- 導入文の終了後に開始する。
- 制限時間は8分（480秒）とする。
- GMが開始操作を行った時点からサーバー側タイマーを開始する。
- 各PLは自己紹介を終えた時点で「自己紹介終わった」を押し、完了状態を全員へ共有する。
- PL7人全員が完了した場合、8分経過前でもGMは自己紹介をスキップしてパック選択へ進める。
- 8分経過後は、未完了者がいてもGMが自己紹介を終了してパック選択へ進める。
- タイマー終了だけでは自動的に次フェーズへ進まず、GMが進行操作を実行する。
- 自己紹介フェーズではHPを表示しない。
- 自己紹介終了後、ルール説明と七獄パック選択へ進む。

各駅の共通進行は次のとおりとする。

1. 駅到着演出
2. 駅固有效果と注意事項の説明
3. GMによるゲーム開始
4. 相談タイマー開始
5. 七獄カード、対象、任意のショップカードの仮選択
6. PLごとの最終確認
7. 7人確定後、GMによる一斉公開
8. 段階別の効果処理と状態反映
9. 次ターン、または駅結果へ進行
10. 第一駅から第六駅では駅順位、支援賞、特殊条件と達成者を、`NarrativeStep`方式の報酬読み上げで発表する。第七駅では駅順位を除く結果を発表する。
11. 第一駅から第六駅では、報酬読み上げ後にココフォリア反映待機へ進む。GMが全報酬を手動反映してWeb上で確認するまで、ショップ、冥貨譲渡、次駅進行は行えない。
12. 全報酬の反映確認後、GMが自由時間開始の読み上げを進め、読み上げ終了時に5分間の自由時間を開始する。
13. 第七駅では自由時間へ進まず、最終結果へ進行する。

時間切れでも未確定者を自動確定しない。GMが未確定者を確認し、本人の確定またはGMテスト機能による補完を行う。

## GM／PLの役割

### GM

- GMはプレイヤーではなく、PL7人の人数、順位、HP、カード選択、対象、与ダメージ、被ダメージ、支援点に含めない。
- カード、冥貨、アイテムを取得または使用しない。
- ルーム作成、ゲーム進行、タイマー、一斉公開、裁定、手動補正を担当する。
- 冥貨の配布、ショップ購入に伴う冥貨の増減、譲渡をココフォリアへ反映する。ショップカード自体はWeb上で管理し、ココフォリアへ反映しない。
- 路線図を非公開で判定し、エンディングを選択する。
- GM進行画面とPL1～PL7の表示を切り替えて確認できる。
- ターン中のGM画面では、PL1～PL7の確定状況、未確定人数、未確定PL、残り時間を一覧で確認できるようにする。
- 時間切れ後も、例えば「PL3・PL6が未確定」のように未確定者を明示する。
- GM権限を要する操作はサーバー側で検証する。

### PL

- PLは必ず7人とし、PL1～PL7の重複しない参加IDで管理する。
- HP、冥貨、七獄パック、ショップカード、使用履歴、支援点などを持つ。
- パック、カード、対象、ショップカードを選択する。
- 会話、相談、嘘、誘導、同盟、裏切り、交渉、取引、路線図作成に参加できる。
- 自分に許可された秘密情報だけを閲覧できる。

## HPルール

- 初期HPは15、最大HPも15とする。
- HPは0未満にならない。
- 駅中に一度でもHP0になったPLは、その駅終了まで「亡者状態」となる。
- 亡者状態でもカード選択、会話、相談、交渉、取引ができる。
- 亡者状態のPLが与える直接ダメージは1減少し、最低0とする。
- 継続ダメージ、駅ダメージ、自傷には亡者状態の直接ダメージ弱体化を適用しない。
- 最大HPを超える回復はHPへ反映しない。
- 駅途中でHP1以上へ回復しても、その駅終了までは亡者状態を継続する。
- 亡者状態のPLは、その駅の駅順位と特殊ボーナスの対象外とする。
- 亡者状態のPLの与ダメージ、支援点、被ダメージ、カード履歴は、通常どおり駅内記録と全体記録へ加算する。
- 駅終了時にHP1以上なら、次駅開始時に亡者状態を解除して通常状態へ復帰する。
- 駅終了時にHP0なら、次駅も亡者状態で開始する。
- 次駅開始時は、持越状態確認、駅開始時の継続ダメージ・回復、HP更新、HP0判定、亡者状態確定、第1ターンの亡者状態スナップショットの順で処理する。
- サーバー内部では仮HPを持ち、ダメージまたは回復イベント1件ごとに0～15へ丸めて更新する。
- HP0へ到達した事実はそのイベント処理時に記録し、ターン終了時の亡者状態更新で `isDeadState === true` 相当の状態を付与する。
- 亡者弱体化はターン開始時点の亡者状態を参照する。ターン途中で初めてHP0になったPLの選択済みカードは通常威力で処理し、次ターンから直接ダメージ−1を適用する。
- 現行35枚ではカード固有の優先度を使用しない。同じフェーズのダメージイベントはPL番号の昇順で処理する。
- 実与ダメージは、イベント直前の仮HPから実際に減少したHPだけを記録し、HP0を超えるオーバーキル分は記録しない。

## 七獄パック

- 初期パックは焦熱、氷結、針山、血の池、餓鬼、修羅、無間の7種類とする。
- 各パックは5枚、合計35枚とする。
- 選択前に公開するのはパック名と得意分野だけとする。
- 詳細なカード内容は、選択した本人とGMだけが確認できる。
- 仮選択中は複数PLが同じパックを選んでもよい。
- 最終的にはPL7人が互いに異なるパックを選ぶ。
- 全パックが重複しない場合に限り、GMが第一駅へ進める。

| パック | 得意分野 | カード |
|---|---|---|
| 焦熱 | 高火力・自傷 | 炎撃、焼身、炎壁、火種、燃え残り |
| 氷結 | 妨害・軽減 | 氷槍、凍結、吹雪、氷壁、雪解け |
| 針山 | 集中攻撃・追撃 | 追い針、針千本、毒針、針避け、標的縫い |
| 血の池 | 回復・吸収 | 吸血、血濁、血の盾、治癒血、輸血 |
| 餓鬼 | 強奪・再利用 | 暴食、強奪、残飯の盾、施し、強欲 |
| 修羅 | 正面戦闘 | 強斬、捨て身、防御、反撃の構え、気勢 |
| 無間 | 特殊操作 | 断絶、無効、反転、回帰、再演 |

カード効果は可能な限りデータ定義する。

| カード | 分類 | 効果 |
|---|---|---|
| 炎撃 | 攻撃 | 対象HP−2。カード一斉公開時点で自分HP7以下なら−3。そのターン中のHP増減では変化しない。 |
| 焼身 | 攻撃 | 対象HP−3。一斉公開直後のHPで使用者HPが対象HP未満なら−4。使用者HP−1。攻撃部分を無効化されても自傷は発生する。 |
| 炎壁 | 防御 | 対象が受ける直接ダメージを合計2軽減。 |
| 火種 | 補助 | 秘密選択時に指定したPLが今回選択した有効な主分類「攻撃」の七獄カードの直接ダメージ＋1。攻撃部分が有効なら、防御後の実ダメージ0でも使用者HP−1。指定不適合または攻撃部分無効時はカード全体が不発となり、HP−1も発生しない。 |
| 燃え残り | 補助 | 自分の攻撃カード1枚へ残火を1つ付与する。そのカードの次回使用時に通常攻撃＋1。 |

### 無間パック

| カード | 分類 | 効果 |
|---|---|---|
| 断絶 | 攻撃 | 対象HP−2。数値軽減とあらゆる完全防御を無視し、それらを消費しない。無効化と対象変更は受ける。 |
| 無効 | 妨害 | 秘密選択時に指定した自分以外のPLのカードについて、攻撃部分とそれに依存する効果、または攻撃部分がなければ持越妨害部分1つを無効化する。カード全体は消さない。 |
| 反転 | 防御 | 使用ターン中、対象が受ける基本直接攻撃のうち最も大きい1件を0にする。上限4適用後・防御前の値の半分（端数切り捨て、最大2）を攻撃者へ反射する。 |
| 回帰 | 回復 | 選択時に指定した対象HP＋2。選択時に指定した解除可能な持越状態1つを解除する。 |
| 再演 | 補助 | 3駅以上前に自分が使用した七獄カードから、直接ダメージ、HP回復、数値軽減の基本数値効果1つを最大2でコピーし、新しい有効な対象を選ぶ。主分類は補助のまま。 |

## カード選択と対象選択

1. PLは七獄パックからカード1枚を秘密に仮選択する。
2. 必要なカードではプレイヤー対象またはカード対象を選ぶ。
3. 仮選択中はカードと対象を何度でも変更できる。
4. PLが「この内容で最終確認」を押すと変更不可になる。
5. GMだけが最終確認を解除できる。
6. 7人全員の最終確認後、GMが一斉公開する。
7. 一斉公開前の選択内容は、本人とGM以外へ送信しない。

対象の基本規則は次のとおりとする。

- 攻撃・妨害：自分以外のPL1人。
- 防御・回復：自分以外のPL1人。
- 補助：カード定義で指定された対象。
- 全体効果：対象選択なし。
- 対象変更後の最終対象を、攻撃処理と集中攻撃判定に使用する。
- カード本文に「自分」または「使用者」と明記された効果だけは、自己対象禁止の例外とする。
- 吸血や暴食の自己回復は、攻撃に付随する吸収効果であり、回復カードの対象選択ではない。
- ショップカードは、本文に自己使用可能と記載されている場合だけ自分へ使用できる。

- 1ターンにつき七獄カード1枚を使用する。
- 各駅では `StationDefinition.turnCount` に設定された回数だけ、七獄カードを選択・使用する。
- ショップカードは1駅につき最大1枚まで使用できる。
- 1つの駅でショップカードを使用した場合、その駅の別ターンでは追加のショップカードを使用できない。

持続期間がカード本文に明記されていないカード効果は、使用ターンだけ有効とする。

## クールタイム

- 七獄カードを使用すると、次の1ターンだけ通常クールタイムになる。
- 使用ターンをTとした場合、T+1では使用できず、T+2から再使用できる。
- 通常クールタイムは駅をまたいで継続し、駅が変わってもリセットしない。
- 無効化、不発、対象不成立でも、そのカードを使用した事実があれば通常クールタイムになる。
- 通常クールタイムはゲーム全体の通算ターンを基準に判定する。`globalTurnIndex` 相当の通算ターン番号を正としてサーバー側で管理する。
- 通常クールタイムはカード選択時と最終確認時の両方で検証する。

例として、T1で`炎撃`を使用した場合、T2では使用不可となり、T3から再使用できる。駅境界でも同様に、焦熱地獄の最終ターンに使用したカードは氷結地獄の第1ターンで使用できず、第2ターンから使用できる。

## カード使用履歴

カード使用履歴は駅単位に集約せず、カードを使用した各ターンについて最低限次の情報を保存する。

- 使用したPLの参加ID
- カードID
- 駅ID
- 駅内ターン番号
- ゲーム全体の通算ターン番号 `globalTurnIndex`
- 使用結果：成立、不発、無効化
- 対象変更後の最終対象
- 通常クールタイム開始ターン
- `COOLDOWN_EXTENSION` の有無と期限
- CT無視を使用した場合の手段と発生源：欲印、`欲張り札`、餓鬼地獄の固有效果、`地獄の鍵`

対象履歴、`追い針`、`再演`、無間地獄の特殊条件は、このターン単位の使用履歴を参照する。無間地獄の「同じカードをゲーム中3回目として使用」の条件はカードIDごとの通算使用回数で判定し、その3回目の使用で効果が成立した場合に達成する。

## カード処理順

画面上では複数の処理をまとめて表示してよいが、サーバー内部では次の順番に固定する。

1. コピー・再演展開
2. 対象変更
3. 無効化
4. 防御・完全防御・反撃・反射の予約
5. 持越状態・状態効果の予約
6. 基本直接攻撃値の生成
7. 条件付き基本攻撃強化
8. 駅・補助・ショップによる攻撃値修正
9. ターン開始時点の亡者状態による直接ダメージ−1
10. 単体直接ダメージ上限4
11. 完全防御の割当
12. 数値軽減の割当
13. 基本直接攻撃を1件ずつ処理し、仮HP・実与ダメージを更新
14. 基本直接攻撃フェーズ終了後、条件付き追加攻撃を判定
15. カード単位の残り上限を計算し、追加攻撃を生成
16. 残存する防御・軽減を追加攻撃へ適用
17. 追加攻撃を処理
18. 駅固有追加ダメージ
19. 反撃・反射
20. 回復・吸収
21. 自傷・代償
22. 最終HP表示
23. 持越状態保存
24. 亡者状態更新
25. 駅スコア・特殊ボーナス判定
26. 使用履歴・クールタイム記録

現行35枚ではカード固有の優先度を使用しない。同じフェーズで逐次処理が必要な場合はPL1からPL7の順で処理する。将来、カード本文またはカード定義に優先度が明示されたカードだけに個別の `priority` を設定する。対象変更後の状態を全員へ示してから後続処理へ進む。

手順24では、そのターン中に一度でもHP0へ到達したPLへ亡者状態を付与する。復帰判定は駅終了時に別途行い、駅終了HPが1以上なら次駅開始時に亡者状態を解除し、HP0なら維持する。

### 単体直接ダメージ上限

七獄カード1枚が同一PL1人へ与える直接ダメージの防御前合計上限は4とする。

計算順は、基本値、カード自身の条件強化、駅固有效果、補助・ショップによる強化、亡者状態による直接ダメージ−1、上限4、防御・軽減の順とする。

上限4には通常攻撃と同じカードから発生する条件付き追加攻撃を含める。反撃、反射、毒・火傷などの継続ダメージ、駅固有ダメージ、自傷・代償は含めない。

条件付き追加攻撃は、全員の基本直接攻撃終了後に条件を判定する。発生時は、そのカードがすでに生成した防御前直接ダメージ値との合計が4以内になる残量だけを生成する。基本攻撃と追加攻撃には防御を別々に適用するが、同じ防御効果の残量を引き継ぐ。

無効化された攻撃カードは集中攻撃判定に数えない。防御・軽減で実ダメージが0でも、カード自体が有効なら集中攻撃判定に数える。

### 完全防御と数値軽減

- 完全防御の最大攻撃判定は、基本直接攻撃だけを対象とする。
- 完全防御は、対象が受ける最も大きい基本直接攻撃1件を無効化する。同値の場合は攻撃者のPL番号の昇順で決定する。
- 完全防御が複数ある場合、`反転`を最優先で最大の基本直接攻撃へ使用し、残りを次に大きい基本直接攻撃へ順番に使用する。
- 数値軽減の合計値は、最も大きい基本直接攻撃から順に消費する。同値の場合は攻撃者のPL番号の昇順とする。
- 追加攻撃は基本攻撃終了後に生成する。基本攻撃で未使用の完全防御・数値軽減残量だけを追加攻撃へ引き継ぎ、防御の割当を後から巻き戻さない。
- 基本攻撃へ使用した完全防御は消費済みとなり、そのカードの追加攻撃には適用しない。
- `反転`が基本直接攻撃フェーズで発動しなかった場合だけ、追加攻撃フェーズへ持ち越し、追加攻撃のうち最大の1件へ適用する。
- `断絶`は数値軽減とあらゆる完全防御を無視する。`断絶`に対して割り当て可能な防御はなく、防御効果を消費しない。ただし、無効化と対象変更は通常どおり受ける。
- `雪解け`、`針避け`、`残飯の盾`、修羅パックの`防御`による軽減は、通常攻撃と追加攻撃だけに適用する。反撃、反射、継続ダメージ、駅ダメージ、自傷、代償には適用しない。
- 複数の追加攻撃に数値軽減残量を割り当てる場合、防御前追加攻撃値の大きい順とする。同値なら、将来カードに明示された `priority`、次に攻撃者のPL番号の昇順で決定する。現行35枚には個別 `priority` がないため、同値時はPL番号順となる。
- 複数PLの防御が同じ対象へ重なった場合、完全防御、数値軽減の順で処理する。同種の防御内では、将来明示された `priority`、次に防御カード使用者のPL番号の昇順で処理する。現行35枚では同種内をPL番号順とする。
- 各防御カードが実際に防いだ数値だけを、その防御カード使用者の支援点と該当する駅スコアへ帰属させる。
- 防御による実軽減量は、「その防御が存在しない場合の実HP減少量」から「その防御適用後の実HP減少量」を引いて算出する。対象の残りHPを超えるオーバーキル予定分は含めない。
- 複数の防御がある場合は既定の適用順に従い、各防御効果が直前の状態から実際に追加で防いだ量を、それぞれの使用者へ帰属させる。

### 反撃と反射

- 共通の反撃・反射は、軽減後の直接実ダメージを1以上受けた場合だけ発動する。
- 実ダメージ0の場合は発動しない。
- 通常の防御・完全防御は反撃・反射ダメージに適用しない。「反撃・反射も軽減する」と明記された効果だけを適用できる。
- 反撃・反射から、さらに反撃・反射は発生しない。
- `反転`は、完全防御した攻撃の力を返す特殊完全防御であり、「実ダメージ1以上」の発動条件の例外とする。

`反転`は使用ターン中、対象が受ける基本直接攻撃のうち最も大きい1件を0にする。反転値は、攻撃側の数値修正、ターン開始時点の亡者弱体化、上限4までを適用し、防御・軽減をまだ適用していない値とする。その半分を切り捨て、最大2を攻撃者へ反射する。攻撃部分が`無効`になった攻撃は候補にしない。`反転`は共通反射条件の例外とし、その反射からさらに反撃・反射は発生しない。

`反転`による反射の実ダメージは、`反転`使用者の総与ダメージと、反射を成果として扱う駅スコアへ帰属させる。ただし、「攻撃カードを使用したこと」を条件とする駅スコアには算入しない。

`血の盾`は、軽減後に対象が合計1以上の直接実ダメージを受けた場合、対象へ最も多くの実ダメージを与えた攻撃者1人へHP−1を反射する。同値の場合は攻撃者のPL番号が若い方を選ぶ。血の池地獄では反射ダメージが1増えてHP−2となる。反射の実ダメージは、血の盾使用者の総与ダメージとして記録する。

### 個別カードの条件判定

- `焼身`は一斉公開直後のHPを比較し、使用者HPが対象HP未満なら基本攻撃を3から4へ強化する。そのターン中のHP変化は参照しない。攻撃部分を無効化されても自傷HP−1は発生する。
- `吸血`は軽減後の直接実ダメージを1以上与えた場合、吸収として使用者HPを1回復する。血の池地獄では吸収回復が1増える。実ダメージ0なら回復しない。
- `暴食`は一斉公開直後に対象HPが使用者HPより高く、かつ軽減後の直接実ダメージを1以上与えた場合、吸収として使用者HPを1回復する。血の池地獄では吸収回復が1増える。
- `捨て身`は、全員の基本直接攻撃フェーズ終了後、そのフェーズ中に使用者が他PLのカードから直接実ダメージを1以上受けたかを判定する。成立時は同じ対象へ追加HP−1を生成する。反撃、反射、駅ダメージ、継続ダメージ、自傷は条件に含めない。攻撃部分を無効化された場合、基本・追加攻撃は発生しないが自傷HP−1は発生する。
- `強斬`は、コピー、対象変更、無効化、防御準備後の最終対象を参照する。最終対象に強斬へ適用可能な有効防御が1つでもあれば強化せず、1つもなければ基本攻撃を2から3へ強化する。
- `反撃の構え`は、秘密選択時に自分以外のPL1人を指定し、そのPLが今回選択した七獄カードだけを監視する。その攻撃で反撃の構え使用者が直接実ダメージを1以上受けた場合、指定PLへHP−2を1回だけ反撃する。

### カードを指定する補助効果

- `火種`、`標的縫い`、`気勢`は、秘密選択時に「指定PLが今回選択した七獄カード」を対象として記録する。一斉公開後、指定PLが実際に選択していたカードへ適用する。
- 対象変更後も、指定したカードそのものへ補助効果が追従する。
- 指定カードが無効化された場合、対応する補助効果も発生しない。
- `火種`または`気勢`が指定した七獄カードに、対応する主分類または数値効果がない場合、その補助カード全体を不発とする。不発でも使用履歴とクールタイムには記録する。
- `火種`は、指定カードが有効な主分類「攻撃」の七獄カードでない場合、強化と使用者HP−1の両方を発生させない。指定カードが攻撃カードでも攻撃部分を無効化された場合は、同様に強化もHP−1も発生させない。攻撃部分が有効で、防御・軽減によって実ダメージ0になっただけの場合はHP−1を発生させる。
- `標的縫い`は、指定PLのカードが対象変更・無効化後も有効な主分類「攻撃」であり、単一の最終プレイヤー対象を持つ場合だけ標的を生成する。その標的へ向かう有効な主分類「攻撃」の七獄カードをPL番号順に最大2枚選び、1枚につきカード全体の直接ダメージを1増加する。反撃、反射、妨害ダメージ、継続ダメージ、駅ダメージは強化しない。強化後も単体直接ダメージ上限4を適用する。条件不成立時は不発とし、別対象へ付け替えない。
- `火種`による使用者HP−1はカード使用の代償として扱う。

### 数値強化の成果帰属

- 攻撃カード自身の基本値と条件付き自己強化は、攻撃カード使用者の基本ダメージ成分として管理する。
- 駅固有效果などカード以外の環境効果による数値修正は、攻撃カード使用者の基本ダメージ成分へ適用する。
- `火種`、`標的縫い`、`気勢`、`燃え残り`など、攻撃カード以外のカード効果が追加する直接ダメージは、それぞれ独立した補助ダメージ成分として、発生源PLとともに保持する。
- 単体直接ダメージ上限4を適用する際は、最初に基本成分を確保し、残りの上限枠へ補助成分を `supportAttributionOrder` 順に追加する。上限を超えた補助成分は効果を発生させない。
- `supportAttributionOrder` の開始PLはゲーム全体の通算ターンごとに1人ずつ巡回する。通算第1ターンはPL1→PL2→…→PL7、第2ターンはPL2→PL3→…→PL7→PL1とし、以後同様に巡回する。
- 防御・数値軽減は基本成分から先に適用し、その後、上限内に採用された補助成分へ `supportAttributionOrder` 順に適用する。
- オーバーキル時も基本成分、採用済み補助成分の順で仮HPへ適用する。補助成分同士は `supportAttributionOrder` 順とする。
- 実際にHPを減らした補助成分だけを、対応する発生源PLの総与ダメージと、条件を満たす駅スコアへ帰属させる。オーバーキル分は記録しない。
- `気勢`が防御へ追加した数値軽減について、実際に追加で防いだ分を`気勢`使用者の支援点へ帰属させる。
- 駅スコアへの加算は各駅の条件に従う。「攻撃カードを使用したこと」を条件とする駅スコアでは、主分類が補助である補助カード使用者を対象にしない。
- ショップカードによる数値強化も、使用者が存在する場合は、その使用者を発生源とする独立した補助成分として同じ規則で処理する。

### 残火

- `燃え残り`の選択時に、自分の攻撃カード1枚を指定して残火を1つ付与する。
- 残火が付与されたカードは、次回使用時の通常攻撃を1増加する。
- 残火は対象カードが一斉公開された時点で消費する。そのカードが無効化されても残火は戻らない。
- 同じカードへ残火を重複して付与できない。
- 未消費の残火は第七地獄終了まで持続する。
- 残火による加算は、単体直接ダメージ上限4の適用前に行う。

### 欲印と再使用権

- `強欲`は、自分が所有する攻撃以外の七獄カード1枚へ欲印を付与する。
- `強欲`自身、ショップカード、すでに欲印が付いているカード、欲張り札予約または欲張り札由来の再使用権があるカードは指定できない。
- 欲印付きカードが次に使用された時点で欲印を消費する。
- そのカードが次のターンに通常クールタイムとなった際、その最初の選択機会だけ通常クールタイムを無視して再使用できる再使用権へ変換する。
- 再使用権はその機会に使用しなければ失効する。同じ機会に餓鬼地獄の固有效果または`地獄の鍵`を選んだ場合も、選択機会終了時に失効する。
- 欲印の再使用権は `COOLDOWN_EXTENSION` を無視できない。
- 欲印はプレイヤーの持越状態ではなくカードマークとして管理し、欲印の消費後に生じる再使用権も通常クールタイムおよび `COOLDOWN_EXTENSION` とは別に記録する。

### 欲張り札予約と再使用権

- `欲張り札`は、選択時点で通常クールタイム中ではなく、欲印、欲張り札予約、`COOLDOWN_EXTENSION`のいずれも付いていない、自分の七獄カード1枚を指定する。
- 指定カードを次にCT無視手段を使わず通常使用した時点で欲張り札予約を消費し、その使用によって次ターンに発生する通常クールタイムを1回だけ無視できる再使用権へ変換する。
- 欲印由来と欲張り札由来の再使用権を、同一カードへ重複して保持できない。
- 欲張り札予約と、それを消費して生じた再使用権は、通常クールタイムおよび`COOLDOWN_EXTENSION`とは別にカード単位で記録し、状態解除の対象外とする。

### 条件判定と対象履歴

- `炎撃`のHP7以下条件はカード一斉公開時点の使用者HPで固定し、そのターン中のHP増減では変更しない。
- `施し`のHP0条件はカード一斉公開時点の対象HPで固定し、そのターン中のHP増減では変更しない。
- `追い針`は、前の地獄駅で使用者が最後に使用した主分類「攻撃」または「妨害」の七獄カードについて、対象変更後の最終プレイヤー対象を参照する。そのカードが無効化されても対象履歴は保存する。該当するカードまたは最終プレイヤー対象の履歴がなければ条件不成立とする。
- `吹雪`は対象変更時点の現在の最終対象を候補から除外し、対象カードにとって有効なプレイヤー対象候補からサーバーがランダムに1人を選ぶ。候補が0人なら対象変更部分だけ不発とし、元対象を維持する。乱数結果を進行ログへ保存する。
- `血濁`は、対象PLがそのターンに受ける通常回復と吸収による自己回復を含む全回復へ適用し、合計回復量を最大2減らす。

### 持越状態の解除

- `雪解け`と`回帰`は、対象PLに解除可能な持越状態がなくても使用できる。この場合、状態解除部分だけを不発とし、`雪解け`の軽減と`回帰`の回復は通常どおり処理する。
- 解除可能な持越状態が存在する場合は、カード選択時に対象PLと解除する状態1つを指定する。
- クールタイム、`COOLDOWN_EXTENSION`、残火、欲印、使用履歴は解除できない。
- 解決前に指定状態が消失した場合も、状態解除部分だけが不発となり、軽減や回復などその他の効果は通常どおり処理する。

### 持越状態のスタック

- すべての持越状態に `stackKey` を設定する。
- 同じ `stackKey` の状態は原則として重複させず、効果値は最も強い値、期限は最も長い期限、残り回数は最も多い回数を採用する。
- 異なる `stackKey` の状態は同時に存在できる。
- 現行35枚の持越状態は、カード本文または状態定義に明記がない限りスタック不可とする。
- `氷槍`と`凍結`による次駅の攻撃ダメージ低下は、共通の `ATTACK_DAMAGE_DOWN` を使用する。同じPLへ両方が付与されても加算せず、最も強い低下値だけを適用する。同値の効果も重複しない。
- `ATTACK_DAMAGE_DOWN` は対象の次の地獄駅において、主分類が「攻撃」の七獄カードが発生させる通常攻撃と追加攻撃へ適用し、最低ダメージは0とする。反撃、反射、継続ダメージ、駅固有ダメージ、自傷には適用しない。
- 火傷は `BURN`、毒は `POISON`、対象制限系は `TARGET_RESTRICTION` を使用する。
- `ATTACK_CARD_RESTRICTION` は現行35枚では使用せず、将来、攻撃カードの使用自体を制限する効果が追加された場合の予約キーとする。
- 残火、欲印、欲張り札予約とその再使用権はプレイヤーの持越状態ではなく、カード単位で別に管理し、状態解除の対象外とする。
- `強奪`によるクールタイム延長は対象カード自体に付与する `COOLDOWN_EXTENSION` として管理する。付与ターンをTとした場合、通常クールタイムの1ターンを含めてT+1・T+2で使用不能となり、T+3から使用できる。通常CT1ターンに追加2ターンを足した3ターン禁止にはしない。
- 同一カードへの `COOLDOWN_EXTENSION` は重複させない。新しい`強奪`を受けた場合は、既存のスタック規則に従い、残存期間が長くなる場合だけ期限を更新する。
- `COOLDOWN_EXTENSION` は、欲印、`欲張り札`、餓鬼地獄の固有效果、`地獄の鍵`では無視できない。
- `COOLDOWN_EXTENSION` はプレイヤーに付与された持越状態ではないため、`雪解け`と`回帰`では解除できない。

### クールタイム例外の競合

- 欲印由来の再使用権、欲張り札由来の再使用権、餓鬼地獄の固有效果、`地獄の鍵`が同じ選択機会に利用可能な場合、1回のカード使用につき利用できるCT無視手段は1種類だけとする。
- PL本人が利用する手段を選び、サーバーは自動選択しない。
- 使用しなかった他の手段を同時に消費しない。ただし、欲印由来と欲張り札由来の再使用権は、そのカードが本来通常クールタイムとなる最初の選択機会だけ有効とする。その機会に餓鬼地獄の固有效果または`地獄の鍵`を選んだ場合も、未使用の再使用権はターン終了時に失効する。
- いずれのCT無視手段も `COOLDOWN_EXTENSION` を無視できない。

### 攻撃付随状態

- `氷槍`、`毒針`を含む攻撃付随の持越状態・継続効果は、その攻撃による直接実ダメージが1以上の場合だけ付与する。
- 攻撃が無効化された場合、または防御・軽減後の実ダメージが0の場合は付与しない。
- 次駅開始時は、持越状態確認、駅開始時の継続ダメージ・回復、HP更新、HP0判定、亡者状態確定、第1ターンの亡者状態スナップショットの順で処理する。

### 無効

- 秘密選択時に、自分以外のPL1人を指定する。指定PLのカード内容は一斉公開まで分からない。
- 指定カードに攻撃部分がある場合、通常攻撃、条件付き攻撃強化、条件付き追加攻撃、攻撃成功依存の吸収・回復、攻撃付随の状態異常・持越妨害・継続ダメージをまとめて無効化する。
- `氷槍`を無効化した場合、今回のHP−1と次駅の攻撃ダメージ−1の両方を無効化する。
- `毒針`を無効化した場合、今回のHP−1と次駅HP−1の両方を無効化する。
- 攻撃部分がないカードの場合だけ、そのカードの持越妨害部分1つを無効化する。
- 独立した防御、独立した回復、自傷・代償、使用コスト、使用履歴、クールタイムは無効化しない。

### 再演

- カード選択時点で有効なコピー候補が1枚も存在しない場合、`再演`は選択できない。UI上で無効化し、選択できない理由を表示する。
- 現在駅から3駅以上前に、再演使用者自身が実際に使用した七獄カードだけをコピー元にできる。
- コピーできるのは、直接ダメージ、HP回復、数値軽減の基本数値効果1つだけとする。
- コピー直後の基本値は、ダメージ、回復、軽減のいずれも最大2とする。
- 条件付き強化、追加攻撃、反撃、反射、状態異常、吸収、自傷・代償、コピー、無効化、対象変更、クールタイム操作はコピーできない。
- 再演使用者が、コピーした効果に対して新しい有効な対象を選ぶ。
- `再演`の主分類は補助のままとし、カード分類を参照する駅効果は適用しない。発生した効果を参照する駅効果は適用する。
- コピー直後の基本値へ、駅固有效果、発生効果を参照するショップカード、亡者弱体化、共通上限を通常どおり適用する。その結果、最終値が2を超えることを認める。
- 直接ダメージをコピーした場合、亡者状態なら直接ダメージ−1を適用し、最終的に共通上限4を適用する。
- 使用履歴には`再演`だけを記録し、コピー元カードを再使用した扱いにはしない。

## 支援点

- 自分の七獄カードで他人の実ダメージを1防ぐごとに1点を得る。
- 自分の七獄カードで他人のHPを実際に1回復するごとに1点を得る。
- 最大HPを超えた余剰回復は数えない。
- 自分自身への防御・回復は数えない。
- 吸収による自己回復は数えない。
- 駅による自動軽減は数えない。
- 駅単位とゲーム全体の支援点を別々に集計する。
- 駅で支援点1以上かつ最多のPL全員へ、支援賞として壱の冥貨を1枚与える。

## 駅固有效果

駅固有效果と隠し特殊ボーナスはデータ定義する。特殊条件はゲーム開始前に公開せず、駅結果で条件と達成者を初めて公開する。

### 第一・焦熱地獄「灼熱」

- 攻撃カードの直接ダメージを1増加する。
- 強化後の直接ダメージが4以上なら使用者HPを1減らす。
- 焦熱固有の自傷と同一カード固有の自傷は重複しない。
- 特殊条件：他人へ実ダメージを合計3以上与える。
- 報酬：壱×1。

### 第二・氷結地獄「極寒」

- すべての直接ダメージを1軽減し、最低0とする。
- 毒、火傷、自傷、駅ダメージには適用しない。
- 特殊条件：自分のカードで、他人が受ける直接ダメージを合計2以上防ぐ。
- 報酬：壱×1。

### 第三・針山地獄「針の集中」

- 同じPLが2人以上の有効な攻撃カードの最終対象になった場合、通常処理後に駅からHPを1減らす。
- 狙った人数にかかわらず、駅ダメージは1ターンにつき最大1とする。
- 特殊条件：他PLと同じ相手を攻撃し、自分の攻撃で実ダメージ1以上を与える。
- 報酬：壱×2。

### 第四・血の池地獄「血潮」

- 回復量を1増加する。
- 吸収による回復量を1増加する。
- 反撃・反射ダメージを1増加する。
- 各カードにつき、それぞれ1まで増加する。
- 特殊条件：自分の七獄カードで実回復を合計3以上発生させる。
- 報酬：壱×2。

### 第五・餓鬼地獄「強欲」

- 各PLは餓鬼地獄中に1回だけ、通常クールタイム中の七獄カードを選択して使用できる。
- 使用不能の理由が通常クールタイムだけの場合に利用でき、`COOLDOWN_EXTENSION` によって使用不能なカードには利用できない。
- この効果で再使用したカードの処理終了後、使用者HPを1減らす。このHP−1は自傷・代償として扱う。
- 再使用したカードも、その使用によって通常どおり次の1ターンの通常クールタイムになる。
- 餓鬼地獄中の使用権はPL1人につき1回だけとし、使用しなかった権利は次駅へ持ち越さない。
- 特殊条件：餓鬼地獄の固有效果を使って通常クールタイム中のカードを再使用し、そのカードの効果を実際に1つ以上成立させる。
- 報酬：壱×2。

### 第六・修羅地獄「修羅の戦場」

- 攻撃カードの直接ダメージを1増加する。
- 防御カードの数値軽減を1増加する。
- 反撃・反射ダメージを1増加する。
- 各カードにつき、それぞれ1まで増加する。
- 特殊条件：他人へ実ダメージ2以上を与え、自分も実ダメージ1以上を受け、駅終了時HP1以上である。
- 報酬：壱×3。

### 第七・無間地獄「六獄再演」

- 焦熱から修羅までの6駅から、ランダムに2つの固有效果を選ぶ。
- 選ばれた効果はカード選択前に全員へ公開する。
- 同種の数値強化は重複せず、大きい値だけを適用する。
- 数値以外の条件と代償は併存する。
- 特殊条件：同じカードをゲーム中3回目として無間地獄で使用し、効果を発生させる。
- 報酬：壱×4。

## 各駅固有の駅スコア

第一地獄から第六地獄では、各ターンの結果から駅スコアを加算し、駅終了時の累計値を駅順位の第一判定基準とする。

- 駅開始時に全PLの `stationScore` を0へ初期化する。
- 各ターンのHP処理とカード効果処理が完了した後に、そのターンの得点を加算する。
- `StationDefinition.turnCount` に設定された全ターンの累計を、その駅の駅スコアとする。
- 隠し特殊ボーナスは駅スコアへ加算しない。
- ショップカード単体の独立効果は、原則として駅スコアへ加算しない。
- ショップカードが七獄カードのダメージ、回復、軽減を強化した場合、強化後の実数値を七獄カード使用者の成果として加算する。
- 亡者状態のPLも駅スコアを記録するが、その駅の駅順位対象からは除外する。

### 第一地獄：焦熱点

その駅で、自分の七獄カードによって他人へ与えた実ダメージ1につき1点を加算する。

対象となる実ダメージ：

- 通常攻撃
- 追加攻撃
- 反撃
- 反射

対象外：

- 自傷
- 毒、火傷などの継続ダメージ
- 駅固有ダメージ

例として、3ターンの実ダメージが3、0、2なら、焦熱点は合計5点となる。

### 第二地獄：氷結点

以下を合算する。

1. 自分の七獄カードによって、他人が受ける実ダメージを1防ぐごとに1点。
2. 自分の七獄カードによって、他人のHPを実際に1回復するごとに1点。
3. 主な分類が「妨害」のカードを有効に成立させたターンは1点。

「妨害成立」とは、対象変更、カード使用制限、持越状態など、カード本文に記載された妨害効果が実際に1つ以上適用された場合を指す。不発または無効化された妨害カードは0点とする。氷結地獄そのものによる直接ダメージ軽減は、誰の氷結点にも加算しない。

### 第三地獄：針山点

各ターン、自分が攻撃カードを使用し、次の両方を満たした場合に2点を加算する。

- 自分の攻撃が実ダメージ1以上を与えた。
- 自分以外のPLも、同じ最終対象へ有効な攻撃カードを使用していた。

同じターンに複数の条件成立があっても、PL1人が得られる針山点は最大2点とする。3ターン設定の場合は最大6点となる。

無効化された他人の攻撃カードは、有効な攻撃として数えない。防御・軽減によって実ダメージ0になった攻撃でも、カード自体が有効なら、同じ対象を攻撃した人数には数える。

### 第四地獄：血潮点

以下の実数値を合算する。

1. 自分の七獄カードで他人を実際に1回復するごとに1点。
2. 自分の七獄カードの吸収によって自分を実際に1回復するごとに1点。
3. 自分の七獄カードによる反撃・反射で実ダメージを1与えるごとに1点。

通常攻撃・追加攻撃によるダメージは血潮点へ加算しない。最大HPを超えた余剰回復も加算しない。

### 第五地獄：餓鬼点

餓鬼地獄の固有效果「強欲」を利用し、通常クールタイム中の七獄カードを再使用した場合に判定する。`COOLDOWN_EXTENSION` 中のカードには固有效果を利用できない。

- 再使用カードの効果が1つ以上実際に成立した場合、1点を加算する。
- さらに、その再使用カードによって実ダメージ2以上、実回復2以上、実軽減2以上のいずれかを満たした場合、追加で1点を加算する。
- 1ターンに獲得できる餓鬼点は最大2点とする。
- 不発または完全に無効化された再使用カードは0点とする。

### 第六地獄：修羅点

自分が他人へ与えた実直接ダメージ1につき1点を加算する。

さらに各ターン、次の両方を満たした場合、追加で1点を加算する。この追加点は1ターンにつき最大1点とする。

- 自分が他人へ実ダメージ2以上を与えた。
- 自分も他PLのカードから実ダメージ1以上を受けた。

対象となる実ダメージ：

- 通常攻撃
- 追加攻撃
- 反撃
- 反射

対象外：

- 自傷
- 継続ダメージ
- 駅固有ダメージ

### 第七地獄：無間

- 無間地獄では駅スコアによる順位と順位報酬を設けない。
- 第七地獄終了後は、ゲーム全体の最終順位を算出する。
- 無間地獄の隠し特殊ボーナスは通常どおり存在する。

## 駅ごとのターン数設定

各駅のターン数は `StationDefinition.turnCount` に保存し、画面、進行、終了判定、テストで同じ設定値を参照する。処理コードへ固定値をハードコードしない。

現在の初期設定値は次のとおりだが、今後の調整対象とする。

| 駅 | `turnCount` 初期設定値 |
|---|---:|
| 第一・焦熱地獄 | 3 |
| 第二・氷結地獄 | 3 |
| 第三・針山地獄 | 3 |
| 第四・血の池地獄 | 3 |
| 第五・餓鬼地獄 | 4 |
| 第六・修羅地獄 | 4 |
| 第七・無間地獄 | 5 |

初期設定の合計は25ターンとする。

この25ターン構成を正式な初期設定として採用する。`StationDefinition.turnCount` を正本とし、合計25や各駅のターン数を進行コードへハードコードしない。約3時間へ収めるための現時点の調整対象は、ターン数ではなく標準進行時間とする。

## プレイ時間・標準時間配分

### 全体目標

- ゲーム全体は180分以内を目標とする。
- 標準終了目標は160～165分程度とし、通常進行では15～20分程度の予備時間を残す。
- 予備時間は、PLの選択遅延、ルール確認、GM裁定、通信トラブル、ココフォリア操作遅延、冥貨処理、エンディング判定確認に使用する。
- 標準予定を180分すべてで埋めず、初期標準時間配分は約162分、予備時間は約18分とする。
- 標準時間は実プレイ計測による再調整候補となる設定値だが、現段階ではターン数を変更しない。

### 導入

ゲーム開始から第一地獄開始までは約20分を標準とする。入室・接続確認、導入読み合わせ、HPと基本ルールの説明、七獄パックの特徴説明、パック選択、既定の8分間の自己紹介をこの時間に含める。導入全体が大幅に超過しないよう、Web上の説明は必要以上に長文化しない。

### ターン進行

第一地獄から第四地獄までの通常ターンは、1ターン約3分を標準とする。

| フェーズ | 標準時間 |
|---|---:|
| 相談・交渉 | 約75秒 |
| カード・対象選択 | 約45秒 |
| 最終確認 | 約20秒 |
| 一斉公開・自動処理 | 約25秒 |
| 結果確認・次ターン移行 | 約15秒 |
| 合計 | 約180秒 |

第五地獄から第七地獄までは、クールタイム例外、ショップカード、持越状態、カード履歴、無間地獄の複合駅効果によって判断要素が増えるため、1ターン最大約3分30秒を標準上限の目安とする。前半と後半で `turnCount` は変更しない。

これらはゲーム進行上の標準値であり、各フェーズを記載秒数で強制終了させるものではない。時間設定をデータ化する場合は、駅ごとに標準相談時間などを設定可能にする。現段階では設定方針だけを定め、実装しない。

### タイマーと時間切れ

- Web画面には現在のフェーズと残り時間を明示する。
- ターン中は通常表示、残り30秒の注意表示、0秒の時間切れ表示を最低限設ける。
- 0秒になっても現在の選択を自動確定しない。
- 時間切れ時はGM画面で未確定PLを明示し、PL本人へ最終確認を促す。
- GMが状況を確認し、必要な場合だけGMテスト機能による補完を行う。

### 駅結果・報酬反映・自由時間

- 第一地獄から第六地獄までの自由時間は各5分、全6回で合計30分とする。
- 駅終了後は、`station result`、`reward narration`、`currency sync wait`、`free time introduction`、`free time`の順に進行する。第七地獄には通常の自由時間を設けない。
- `reward narration`では、駅終了演出、駅順位、順位報酬、支援賞、隠し特殊条件、特殊ボーナス達成者、PL別の最終獲得冥貨を順に読み上げる。文面と特殊条件は`StationDefinition.rewardFlow`で駅ごとに設定可能とする。
- 読み上げ終了後は、PL1～PL7ごとに順位、順位報酬、支援賞、特殊ボーナス、合計獲得壱を一覧表示する。
- `currency sync wait`では、Webが配布内容を冥貨トランザクションとして示し、GMがココフォリアへ手動で反映した後に各件を「反映済み」にする。Webはココフォリアを自動操作しない。
- 未反映の駅報酬が1件でもある間は、ショップ購入、冥貨譲渡、自由時間開始、次駅進行を禁止する。全件反映済みでも自動遷移せず、GMの操作だけで自由時間開始の読み上げへ進む。
- `free time introduction`の読み上げ終了時に、初めて5分タイマーを開始する。
- 自由時間中はPLの休憩、会話、密談、交渉、ショップ購入、冥貨譲渡申請、路線図操作と、GMの購入・譲渡処理、次駅準備を並行して行う。
- 駅スコア、駅順位、支援賞、隠し特殊ボーナス達成者、冥貨配布内容、HP、亡者状態のうちWebで算出可能なものは、原則としてWebが自動計算して表示する。
- 第一・焦熱地獄の支援賞は駅支援点1以上かつ最多のPL全員に壱×1、特殊ボーナスは亡者状態にならずに他人へ実ダメージ合計3以上を与えたPLに壱×1とする。

## 冥貨

- ゲーム開始時のPLの所持冥貨はすべて0枚とする。

- ゲーム中の通常通貨は原則として壱の冥貨とする。
- 駅順位報酬、支援賞、隠し特殊ボーナスなどの通常報酬は、価値相当枚数の壱で支給する。
- 弐、参、伍、漆の特殊冥貨を通常報酬として直接配布しない。特殊冥貨を初めて入手する基本経路はショップのおつりとする。

### 素数冥貨

| 種類 | 価値 | 裏面の基本役割 |
|---|---:|---|
| 弐 | 2 | 90度回転させ、縦または横に使える直線レール |
| 参 | 3 | 90度単位で回転できる90度カーブレール |
| 伍 | 5 | 地獄環状線から天国方面へ分岐するT字型または同等の分岐レール |
| 漆 | 7 | 天国駅で列車を停車させる終着ホーム |

- 特殊冥貨は2、3、5、7の素数額面だけとし、四、六などの合成数額面は作らない。
- 素数冥貨は通常の買い物用通貨としてショップへ再投入せず、PL間の譲渡、ココフォリア上の路線図作成、裏面断片の確認に使用する。
- ショップへの支払いには原則として壱だけを使用する。
- 壱の裏面は地獄の紋章などの通常意匠とし、路線図完成へ直接必要な主要パーツにはしない。
- 同額面はゲーム判定上すべて同じ機能を持ち、回転によって向きを調整できる。特定の個体だけを正解条件にしない。
- 画像素材には装飾や線路模様の差を付けてよいが、同額面に別機能を持たせない。
- 使用済み、支払い済みの冥貨は再使用、譲渡、路線図作成に使えない。
- 他人のココフォリア上の冥貨をPLが直接操作してはならない。

### Webとココフォリアの役割分担

- Webは、配布予定、購入処理、おつり発生、譲渡申請、冥貨処理のココフォリア反映状態、訂正履歴を管理する。ショップカードの所持・使用はWebのみで管理する。
- ココフォリアは、PLが実際に所持・操作できる冥貨、路線図上へ配置された冥貨、使用済み・支払い済み冥貨の物理状態を管理する。
- Webとココフォリアの状態が一致しない場合、どちらか一方を無条件で正とはせず、ゲーム内で確定済みの処理履歴から本来あるべき所有・使用状態をGMが確定し、ココフォリアをその状態へ合わせる。
- 最終整線終了時点の路線図における位置と向き、および最終エンディング判定については、ココフォリア上の盤面を正とする。
- Webからココフォリアを自動操作しない。

### 不一致の確認と判定

不一致発生時、GMは次の順で確認し、本来あるべき冥貨状態を確定する。

1. Webの取引、配布、購入、おつり、譲渡履歴
2. GMが処理済みにした時刻
3. ココフォリア上の現在の冥貨配置
4. 必要に応じて直前のGM操作内容

最低限、次の不一致を訂正対象として想定する。

- Webでは配布済みだが、ココフォリアで未配布
- ココフォリアでは配布済みだが、Webでは未処理
- ショップ購入時のおつりの渡し忘れ、または誤額面の配布
- 譲渡確定後のココフォリア所有者変更漏れ
- PLまたはGMによる冥貨の誤削除、誤複製、別エリアへの誤移動
- 使用済み冥貨の使用可能エリアへの誤復帰
- 使用可能な冥貨の誤った使用済み化
- 路線図上の冥貨所有者とWeb上の所有者記録の不一致

### GM専用の冥貨訂正

- 冥貨訂正はGMだけが実行でき、PL画面から操作できない。サーバー側でもGM権限を検証する。
- GMは対象PL、冥貨種別、訂正内容、枚数、訂正理由を指定する。
- 冥貨種別は壱、弐、参、伍、漆とする。
- 訂正内容は追加、減少、所有者変更、使用済み化、使用可能への復帰とする。
- 訂正理由は自由記述または、配布忘れ、おつり渡し忘れ、額面間違い、譲渡反映漏れ、ココフォリア誤操作、Web記録誤り、GM裁定、その他などの定型理由から選択できるようにする。
- PLはWeb上で枚数増減、使用状態変更、購入取消、譲渡済み冥貨の復帰を行えない。不一致に気付いた場合はGMへ申告し、GMが履歴を確認する。

訂正は次の順で処理する。

1. GMがWebへ訂正内容を記録する。
2. GMがココフォリア上の冥貨を実際に修正する。
3. GMがWeb上で「ココフォリア反映済み」にする。

Web上の訂正状態は、少なくとも「訂正記録済み・ココフォリア未反映」と「ココフォリア反映済み」を区別する。Web上の訂正操作だけでココフォリアを変更しない。

### 通常処理と反映状態

- 駅順位報酬、支援賞、特殊ボーナス、ショップ購入に伴う壱の使用・おつり、冥貨譲渡について、Web上でココフォリアへの冥貨反映済み・未反映を確認できるようにする。ショップカード自体は反映対象外とする。
- GMがココフォリア上で冥貨を処理した後に、該当する冥貨処理を反映済みへ変更する。
- ショップ購入は、投入した壱、獲得商品、おつりの素数冥貨を1つの購入トランザクションとして関連付け、取引ID相当で追跡できるようにする。ただしココフォリア反映の対象は投入した壱とおつりの冥貨だけであり、商品はWeb上のみで所持・使用を管理する。

### 冥貨譲渡

冥貨譲渡は次の順で処理する。

1. PLが自由時間のWeb「冥貨」タブで、相手、冥貨種別、枚数を指定してGMへ申請する。
2. GMが申請と譲渡可能状態を確認する。
3. Web上で譲渡処理を確定する。
4. GMがココフォリア上の所有状態を変更する。
5. GMがWeb上でココフォリア処理済みをチェックする。

PL同士がココフォリア上で他人の冥貨を直接移動してはならない。途中で不一致が生じた場合は、確定済み取引履歴を基準にGMが訂正する。

### 所有・使用・配置状態

- 素数冥貨を路線図へ配置しても所有権は失わず、所有する使用可能冥貨の位置を移動したものとして扱う。
- Webは所有者、使用可能または使用済み、路線図へ配置中かを分けて管理できるようにする。
- 路線図上の正確な座標と回転角はWebで同期せず、ココフォリアを正とする。
- 使用済み冥貨は再支払い、譲渡、路線図への使用ができない。
- 履歴上使用済みである冥貨が誤って使用可能エリアへ戻された場合、GMは使用済みエリアへ戻す。履歴から誤って使用済みにされたことを確認できた場合は、GM訂正により使用可能へ復帰できる。

### 訂正履歴と表示範囲

すべてのGM訂正について、最低限次の情報を履歴へ保存する。

- 訂正ID
- 対象ゲームまたはルーム
- 対象PL
- 冥貨種別
- 訂正前と訂正後の状態
- 増減枚数
- 訂正理由
- GM操作
- 訂正日時
- ココフォリア反映状態

訂正履歴を完全に削除して痕跡をなくしてはならない。誤った訂正を修正する場合は新しい訂正履歴を追加する。詳細な訂正履歴やGM内部メモは他PLへ公開せず、対象PLには必要に応じて「GMにより冥貨所持数が訂正されました」程度を表示する。他PLの所持情報は開示しない。

### GM確認画面と最終整線前チェック

- GM画面ではPL1～PL7のWeb上の冥貨所持記録、壱・弐・参・伍・漆ごとの枚数、使用可能・使用済み状態、未反映処理件数を確認できるようにする。
- 未反映処理は、報酬、おつり、譲渡、訂正などの種類別に確認できるようにする。
- 自由時間終了前と最終整線開始前に「未反映処理：0件」であることを確認しやすくする。
- 最終整線開始前には、駅順位報酬、支援賞、特殊ボーナス、購入おつり、冥貨譲渡、訂正に未処理・未反映がないか確認する。
- 未反映処理があっても進行を絶対禁止にはしないが、件数を示し、最終整線を開始するかGMへ強く警告する。

### 最終整線中・終了後の訂正と補正配置

- 最終整線中に、本来成立していた処理がGMまたはシステムの反映漏れにより盤面へ反映されていないと判明した場合は、GMによる訂正を認める。
- 最終整線3分終了後、エンディング判定前に、GMはWeb上の確定済み冥貨処理とココフォリア上の冥貨状態を最終監査する。
- Web上で取得・所有が確定していた冥貨が、GMまたはシステムの反映漏れによりココフォリア上に存在しなかったことを確認できた場合だけ、その冥貨を復元して補正配置を認める。
- 補正配置で操作できるのは、反映漏れにより新たに復元された冥貨だけとする。その所有者は復元冥貨の配置、裏返し、回転を行える。
- 復元冥貨の配置場所と向きは、所有者が現在の盤面を見て自由に決定する。
- すでに盤面上に存在する他の冥貨は、移動、回転、交換、再配置できない。
- 新規の譲渡、ショップ購入、その他の取引は禁止する。
- 補正配置は原則30秒とし、反映漏れ冥貨が複数ある場合も合計60秒を上限とする。
- 復元冥貨があれば既存配置も変更していたという理由で、最終整線全体をやり直すことはできない。
- 補正配置を認める期限はエンディングの確定・公開前までとし、公開後は新しい配置機会を与えない。

次の事由は運用事故ではなくPLのゲーム上の結果として扱い、訂正または補正配置の対象にしない。

- 所持冥貨の置き忘れ
- 裏返し忘れ
- 回転または向きの間違い
- 配置場所の間違い
- 譲渡し忘れ
- 購入し忘れ
- 相談不足
- 路線図の推理ミス
- 漆をホームとして使用しなかったこと

最終処理は次の順に固定する。

1. 最終整線3分を終了する。
2. GMが未反映処理と冥貨状態を最終監査する。
3. 必要な場合だけ補正配置を行う。
4. ココフォリア盤面をロックする。
5. GMが天国線とホームの成立を非公開で判定する。
6. エンディングを確定する。
7. PLへエンディングを公開する。

## ショップ

- 各ショップは、対応する地獄駅の終了後から次の地獄駅へ出発するまでの自由時間だけWeb上で購入できる。過去のショップ商品は後の自由時間に表示・購入できない。
- 商品は表示価格と、購入時に投入する壱の枚数を別々に持つ。
- 購入時の投入額はPLが選択しない。第一・第二ショップでは必ず壱×5、第三～第六ショップでは必ず壱×10を投入する。
- 購入成立時、商品ごとに定義された素数冥貨1枚をおつりとして受け取る。特殊冥貨はショップへの支払いに使用できない。
- 各商品は在庫1枚とする。
- ショップカードは1駅につき最大1枚使用できる。
- 使用したショップカードはゲームから除外し、再使用できない。
- 未使用カードは次駅以降へ持ち越せる。
- ショップカードにクールタイムはない。
- ショップカード単体では隠し特殊ボーナスを達成できない。
- 支払った冥貨は路線図に使用できない。

### 公開範囲と購入競合

- 商品名、表示価格、購入時に必要な壱の投入枚数、商品効果、在庫ありまたは`SOLD OUT`の状態は全PLへ公開する。
- 誰が何を購入したか、所持ショップカード、購入申請内容、使用前のショップカード選択は本人とGMだけに開示し、権限のないクライアントへ送信しない。
- 一斉公開後は、使用したショップカード、使用者、実際に発生した効果を全PLへ公開する。
- 売り切れの事実は全PLへ公開するが、購入時点では購入者名を他PLへ公開しない。
- 同じ在庫1の商品へ複数の購入申請があった場合、サーバーが支払い可能であることを確認し、購入処理を受理した順の先着とする。
- 後から処理されたPLには「他のプレイヤーが先に購入しました」とだけ表示し、購入者名を表示しない。

### おつりの記録と初回演出

- おつりの素数冥貨は購入者の所持冥貨へ追加し、GMがココフォリア上でも対応する冥貨を渡す。
- Webは受け取った額面、枚数、受取理由がショップのおつりであることを最低限記録する。
- ゲーム中で初めて購入が成立し、初めて素数冥貨がおつりとして発生した場合は、小鬼がおつりを渡す短い専用演出を表示する。
- 初回演出では額面と通常の壱とは形が異なることまで示せるが、裏面の意味、路線図との関係、正解用途は説明しない。
- 演出本文は後から調整可能なテキストデータとして管理する。
- 小鬼は素数を意味深に示唆してよいが、特別な払い方、路線図の正解、天国への接続方法、ホームの必要性を説明しない。

## 自由時間

- 第一駅から第六駅まで、各駅終了後に実施する。
- 制限時間は5分とする。
- 休憩、Discordでの会話、別車両での密談、相談、交渉、冥貨譲渡、ショップ購入ができる。
- 路線図操作、購入・譲渡処理、次駅準備は、可能な範囲で自由時間と並行して行う。駅報酬のココフォリア反映は自由時間の開始前に完了させる。
- ショップ購入受付は残り0秒で終了する。
- 準備完了者は「自由時間をスキップしたい」を押せる。
- 7人全員が押しても自動出発しない。
- GMが全員の帰還と処理完了を確認し、「次の駅へ」を押した場合だけ進行する。

## 駅順位と最終順位

駅順位は第一地獄から第六地獄まで決定する。第七地獄では駅順位を決定せず、最終順位を決定する。

その駅で一度もHP0になっていないPLだけを駅順位の対象とする。亡者状態のPLは、回復後の終了HPにかかわらず順位対象外とする。

順位対象者を次の優先順で比較する。

1. 駅スコアが高い。
2. 駅終了時の残りHPが高い。
3. その駅で与えた実ダメージが多い。
4. その駅の支援点が多い。
5. その駅で受けた実ダメージが少ない。
6. すべて同じ場合は同順位。

駅順位報酬は次のとおりとする。

| 順位 | 報酬 |
|---|---|
| 1位 | 壱×3 |
| 2位 | 壱×2 |
| 3位 | 壱×2 |
| 4位 | 壱×1 |
| 5位 | 壱×1 |
| 6位以下 | なし |

- 同順位は競技順位方式で処理する。例として1位が2人なら、次の順位は3位になる。
- 同順位者全員が、その順位に設定された報酬を得る。
- 同順位によって飛ばされた順位の報酬は配布しない。
- 順位報酬、支援賞、特殊ボーナスは重複して獲得できる。
- 亡者状態のPLは特殊ボーナスの対象外だが、支援賞の判定に使う支援点は通常どおり記録する。

最終順位は次の優先順で決定する。

1. 第七駅終了時の残りHPが高い。
2. 全ゲームの総与ダメージが多い。
3. 全ゲームの総支援点が多い。
4. 全ゲームの総被ダメージが少ない。
5. すべて同じ場合は同順位。

## ココフォリア路線図

### 盤面と発見構造

- ココフォリア上には、ゲーム開始時から七つの地獄を巡る地獄環状線を表示する。
- 地獄環状線の一部から上方の天国へ向かう位置に、不自然に途切れたレール端と空白を配置する。
- 空白には冥貨と同程度の大きさの薄い円形の摩耗跡を設け、PL自身が素数冥貨の裏面を使う可能性に気付ける構造とする。
- PLへ冥貨の配置、路線図完成、天国への接続を直接指示しない。
- PL画面には路線、空白、摩耗跡、不自然な切れ目だけを示し、GM管理用の位置ラベル、正解スロット、必要額面、正しい向き、必要残数を表示しない。
- Webは路線図を自動操作せず、正解判定やヒントをPLへ表示しない。路線図の実物状態はココフォリア上を正とする。

### 天国線の正解配置

GM内部では正解位置をA～Fとして管理できる。A～Fのラベルや正解内容はPLへ表示しない。

| 位置 | 役割 | 正解パーツ |
|---|---|---|
| A | 地獄環状線から天国線へ分岐 | 伍 |
| B | 分岐直後の直線 | 弐 |
| C | 第一カーブ | 参 |
| D | 中間直線 | 弐 |
| E | 天国直前カーブ | 参 |
| F | 天国駅 | 漆 |

天国接続に必要な線路は、地獄環状線、伍、弐、参、弐、参、天国の順で構成する。必要最低数は伍1枚、弐2枚、参2枚の合計5枚とする。所定位置に額面を置くだけでは成立せず、各冥貨を正しい向きへ回転させ、レールの入口と出口が途切れず一本の連続した路線として接続している必要がある。

正しい天国線が1本成立していれば、盤面の別の場所に余分な冥貨があっても接続成立とする。ただし、正解線路上に誤った冥貨や向きの違うレールが入り、接続が途切れている場合は不成立とする。

### 天国駅での終着成立

- 漆は地獄環状線を破壊する車止めではなく、天国側の終点Fへ設置する終着ホームとする。
- 天国線だけが完成している場合、列車は天国付近を通過して地獄廻線へ戻る。
- 天国線が成立し、Fに漆が正しく設置されている場合だけ、天国駅での終着が成立する。
- 天国行きに必要な最低数は伍1枚、弐2枚、参2枚、漆1枚の合計6枚とする。
- `戦傷薬`と`閻魔の眼`から得られる2枚の漆は同じホーム機能を持ち、どちらか一方だけで終着を成立させられる。

### 所有者をまたいだ共同配置

- 天国線の全パーツを1人が所有する必要はなく、複数PLが各自の冥貨を配置して一本の路線を完成させてよい。
- PLは自分が所有する使用可能な素数冥貨だけを裏返し、移動、回転できる。他PLの冥貨を直接操作できない。
- 使用済み、支払い済みの冥貨は路線図へ使用できない。ショップのおつりとして受け取った未使用の素数冥貨は使用できる。
- PLはDiscord上で配置を相談し、必要に応じて素数冥貨を譲渡できる。
- 正解に使わない素数冥貨は手元に残す、別の場所に置く、譲渡する、試行錯誤へ使うことができる。余剰冥貨が存在するだけでは失敗にならない。
- 全22商品の購入を必要条件とせず、特定の商品1つを買い逃しただけで最高エンディングが不可能になる構造にしない。

### 最終整線

- 第七地獄終了後、エンディング判定前に3分間の最終整線を行う。
- 最終整線中、PLは自分の使用可能な素数冥貨を裏返す、移動する、回転する、他PLと相談する、各所有者が協力して配置することができる。
- 最終整線中は、戦闘カードの使用、ショップ購入、新しいショップカードの使用、駅スコア処理を行わない。
- 小鬼は終点が近いことや手元の冥貨を確認するよう促してよいが、冥貨を裏返すこと、線路完成、天国への接続、漆の用途、必要な残り枚数を説明しない。
- 最終整線3分の終了後は通常の冥貨操作を停止する。GM最終監査で反映漏れが確認された場合だけ、復元冥貨に限って補正配置を認める。

### GM最終判定

補正配置の要否を確認して盤面をロックした後、GMはPLへヒントを出さず、次の順でココフォリア上の盤面を非公開確認する。

1. 天国線の分岐開始点を確認する。
2. 伍が地獄環状線から正しく分岐しているか確認する。
3. 弐、参、弐、参が正しい方向で接続しているか確認する。
4. 天国まで一本の路線として到達しているか確認する。
5. 天国接続成立時だけ、天国駅に漆のホームが正しく設置されているか確認する。
6. 条件に応じて3種類のエンディングから1つを選択する。

GMは判定中に、向きの違い、不足枚数、漆の必要性、正解位置をPLへ伝えない。WebではGMが最終的なエンディングを選択し、対応する内容だけをPLへ表示する。
